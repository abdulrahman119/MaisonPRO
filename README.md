# MaisonPRO — موقع الوساطة العقارية في جيبوتي

موقع إلكتروني تفاعلي وحديث للوساطة العقارية في جيبوتي، يربط **الملاك بالمستأجرين والمشترين**.
مبني بـ HTML + CSS + JavaScript خالص (بدون أي مكتبات أو أدوات بناء)، واللغة الأساسية هي **العربية مع دعم كامل لاتجاه RTL**، إضافة إلى الفرنسية والإنجليزية.

---

## 1. النسخة التجريبية (Demo)

الموقع يعمل مباشرة — لا يحتاج إلى تثبيت أو بناء:

```bash
# بأي خادم ملفات ثابت (اختر واحداً)
python3 -m http.server 8080
# أو
npx serve .
```

ثم افتح: `http://localhost:8080`

> يمكن أيضاً فتح `index.html` مباشرة في المتصفح، لكن يُفضّل استخدام خادم محلي لتشغيل كل الوظائف بشكل صحيح.

### ميزات إضافية
- **مفضلة** محفوظة في المتصفح + فلتر "المفضلة فقط".
- **تحويل العملة** DJF ⇄ USD بضغطة واحدة.
- **ترتيب** النتائج (الأحدث / السعر / المساحة).
- **مشاركة العميل**: رابط مباشر لأي عقار عبر `?property=MP-1041`.
- **تنبيهات Toast**، وحالات فراغ واضحة، وأزرار عائمة (واتساب + العودة للأعلى).
- **وصولية**: تسميات ARIA، تنقل بلوحة المفاتيح، `focus-visible`، احترام `prefers-reduced-motion`.
- **وضع بدون JavaScript**: رسالة توضيحية برقم واتساب.

## 4. تخصيص الموقع قبل النشر

### أ) رقم الواتساب ومعلومات الاتصال
كل الإعدادات في مكان واحد: `assets/js/data.js` ← الكائن `SITE_CONFIG`

```js
const SITE_CONFIG = {
  whatsapp: '25377690223',        // ← ضع رقمك هنا (بدون + وبدون مسافات)
  whatsappDisplay: '+253 77 69 02 23',
  phone: '+253 21 35 12 34',
  email: 'contact@maisonpro.dj',
  addressAr: 'شارع بورقيبة، وسط المدينة، جيبوتي',
  addressFr: 'Boulevard Bourguiba, Centre-ville, Djibouti',
  djfPerUsd: 177.721,             // سعر صرف الدولار
  maxImages: 6,
  pageSize: 6                     // عدد البطاقات في كل تحميل
};
```

> ملاحظة: توجد نسخ من الرقم مكتوبة نصياً داخل `index.html` (في الهيدر والفوتر وقسم التواصل) — ابحث عن `77 69 02 23` واستبدلها.

### ب) العقارات
أضف أو عدّل العقارات في `assets/js/data.js` ← المصفوفة `PROPERTIES`:

```js
{
  id: 'MP-2001',
  title: { ar: 'شقة في حيرون', fr: 'Appartement à Héron', en: 'Apartment in Heron' },
  description: { ar: '...', fr: '...', en: '...' },
  type: 'apartment',            // apartment | villa | house | office | studio
  deal: 'rent',                 // rent | sale
  district: 'heron',            // معرّف من مصفوفة DISTRICTS
  price: 280000,                // بالفرنك الجيبوتي (شهرياً إذا كان إيجاراً)
  rooms: 3, baths: 2, area: 140,
  floor: 2, year: 2020,
  featured: true, isNew: true, postedDays: 2,
  images: ['apt-1', 'kitchen-4'],   // أسماء الملفات داخل assets/img (بدون .jpg)
  amenities: ['ac', 'parking'],     // مفاتيح من الكائن AMENITIES
  owner: { name: 'خديجة علي', phone: '25377455678' }
}
```

### ج) الأحياء
عدّل مصفوفة `DISTRICTS` في نفس الملف — ستُحدَّث تلقائياً في قائمة الفلترة وفي قسم "مناطق التغطية" وفي قائمة الجوال.

## 5. كيف تعمل الوظائف

- **الفلترة** تجري فورياً في الذاكرة على `PROPERTIES` (بدون إعادة تحميل)، وتُحدَّث الأعداد وأشرطة الفلاتر والحالة الفارغة تلقائياً.
- **واتساب**: يُبنى الرابط `https://wa.me/<الرقم>?text=<الرسالة>` مع `encodeURIComponent`، لذلك يعمل على الجوال (يفتح التطبيق) وسطح المكتب (يفتح WhatsApp Web).
- **رفع الصور**: تُضغط الصور في المتصفح عبر `canvas` قبل حفظها لتجنّب تجاوز مساحة `localStorage`.
- **البيانات المضافة تجريبياً** تُخزَّن في `localStorage` (مفاتيح `maisonpro:submissions:v1` و`maisonpro:favorites:v1` و`maisonpro:lang`) وتظهر فوراً أعلى القائمة.

> ⚠️ لأن الموقع ثابت (Static)، فإن إعلانات الملاك تُحفظ **في متصفح الزائر فقط** وتُرسل نسخة منها إلى واتساب. لاستقبالها في قاعدة بيانات تحتاج إلى ربط خلفية (Backend) أو خدمة مثل Formspree / Google Forms / Supabase.

---

## 6. للانتقال إلى الإنتاج (اختياري)

1. **Backend للنموذج**: استبدل حفظ `localStorage` في `submitProperty()` بطلب `fetch()` إلى واجهتك البرمجية أو خدمة نماذج.
2. **صور حقيقية**: استبدل `assets/img/*.jpg` بصورك (يفضّل WebP وبأبعاد 1200×900).
3. **قاعدة بيانات**: انقل `PROPERTIES` إلى API للحصول على إعلانات قابلة للإدارة.
4. **التحسينات**: الموقع لا يستخدم أي مكتبات خارجية عدا خطوط Google، ويمكن استضافته على أي استضافة ثابتة (Netlify، Vercel، GitHub Pages).
