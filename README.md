# MaisonPRO — عقارات جيبوتي

موقع ثابت (HTML + CSS + JavaScript بلا مكتبات) للوساطة العقارية في جيبوتي، يربط الملاك بالمستأجرين والمشترين. العربية هي اللغة الأساسية مع RTL كامل، إضافة إلى الفرنسية والإنجليزية.

> 📌 **خطة الإطلاق خطوة بخطوة:** [`LAUNCH.md`](LAUNCH.md) — ابدأ منها إذا كان هدفك نشر الموقع.

---

## التشغيل

```bash
npm run serve          # أو: python3 -m http.server 8080 --bind 0.0.0.0
# افتح http://localhost:8080
```

للنشر:

```bash
npm run check          # فحص الترجمات والملفات قبل الإطلاق
npm run build          # يولّد dist/ الجاهز لـ Netlify / Vercel
```

`netlify.toml` و `vercel.json` يضبطان أمر البناء ومجلد النشر تلقائياً. التفاصيل ومتغيرات البيئة في `LAUNCH.md`.

## الميزات

- **بحث وفلترة فورية**: نوع العملية (إيجار شهري / يومي / بيع)، نوع العقار، الحي (12 حياً)، الميزانية، الغرف، ترتيب النتائج، المفضلة.
- **ثلاث لغات** مع تبديل اتجاه الصفحة، وحفظ الاختيار، وروابط `?lang=fr` قابلة للمشاركة.
- **عملات**: DJF أساساً مع تحويل تقريبي إلى USD / EUR.
- **تفاصيل العقار**: معرض صور، مواصفات، مرافق، موقع، بطاقة المستشار، رابط مباشر `?property=MP-1041`.
- **واتساب**: رسائل جاهزة تتضمن اسم العقار ورقمه وحيّه وسعره.
- **روابط فلترة قابلة للمشاركة**: `?type=villa&deal=sale&district=heron&q=...` و `?property=MP-1041` و `?lang=fr`.
- **«أضف عقارك»**: تحقق من المدخلات، ضغط الصور في المتصفح، رقم طلب، متابعة الحالة، وإرسال إلى خدمة نماذج خارجية عند تفعيلها.
- **لوحة إشراف تجريبية**: مراجعة الطلبات ونشرها أو رفضها (تعمل محلياً في متصفح الزائر).
- **الوصولية**: ARIA، تنقل بلوحة المفاتيح، `focus-visible`، احترام `prefers-reduced-motion`، رسالة عند تعطيل JavaScript.
- **SEO وأمان**: canonical/hreflang/JSON-LD موحّدة، sitemap، robots، OG، ترويسات أمان و CSP في الاستضافة، تخزين مؤقت طويل للأصول.

## التخصيص

### 1. بيانات الموقع — `assets/js/data.js`

```js
const SITE_CONFIG = {
  whatsapp: '25377690223',   // دولي، بدون + ولا مسافات
  phone: '+253 21 35 12 34',
  email: 'contact@maisonpro.dj',
  djfPerUsd: 177.721,
  djfPerEur: 192.5,
  demoMode: true,            // ← false يوم الإطلاق الرسمي
  forms: { provider: 'none', endpoint: '', apiKey: '' }
};
```

> رقم الواتساب مكتوب أيضاً نصياً في `index.html` (الهيدر، الفوتر، التواصل، `<noscript>`، JSON-LD) وفي `privacy.html` / `terms.html` — ابحث عن `77 69 02 23` واستبدله في كل المواضع.

### 2. الإعلانات — `PROPERTIES`

```js
{
  id: 'MP-2001',
  title: { ar: 'شقة في حيرون', fr: '...', en: '...' },
  description: { ar: '...', fr: '...', en: '...' },
  type: 'apartment',       // apartment | villa | house | office | studio
  deal: 'rent',            // rent | daily | sale
  district: 'heron',       // معرّف من DISTRICTS
  price: 280000,           // DJF (شهري للإيجار، إجمالي للبيع)
  nightly: 16000,          // DJF لليلة (للإيجار اليومي)
  rooms: 3, baths: 2, area: 140,
  featured: true, isNew: true, postedDays: 2,
  images: ['apt-1', 'kitchen-4'],   // داخل assets/img بدون الامتداد
  amenities: ['water', 'power', 'generator', 'ac'],
  owner: { name: '...', phone: '25377...' }
}
```

`DISTRICTS` و `TYPES` و `AMENITIES` في نفس الملف تتغذّى منها قوائم الفلترة والفوتر تلقائياً.

### 3. إعدادات النشر (لا تُحرَّر يدوياً في الإنتاج)

`tools/build.mjs` يقرأ متغيرات البيئة ويولّد `dist/assets/js/runtime.js`:

| المتغير | المعنى |
|---|---|
| `SITE_URL` | عنوان الموقع النهائي (يُقرأ تلقائياً من Netlify/Vercel إن لم يُضبط) |
| `DEMO_MODE` | `1` شريط تنبيه + `noindex` · `0` إطلاق رسمي |
| `FORMS_PROVIDER` | `none` \| `formspree` \| `supabase` |
| `FORMS_ENDPOINT` | رابط استقبال الطلبات |
| `FORMS_API_KEY` | مفتاح Supabase `anon` العام فقط |

القيم الافتراضية في `assets/js/runtime.js` تكفي للتطوير المحلي: وضع تجريبي + حفظ محلي + واتساب.

## كيف تعمل البيانات

- كل قراءة/كتابة للإعلانات تمر عبر `MPStore` في `store.js`. لربط قاعدة بيانات حقيقية، استبدل دوال `list / upsert / transition / remove` بطلبات `fetch` ولا حاجة لتغيير باقي الملفات.
- نموذج «أضف عقارك» يحفظ نسخة محلية دائماً (لمتابعة الحالة)، ويُرسل الحقول النصية إلى `MPForms` عند ضبط مزوّد. **الصور لا تُرسل** للخادم؛ تُضغط في المتصفح وتُشارك عبر واتساب.
- المفضلة واللغة والعملة محفوظة في `localStorage`.

> ⚠️ **النسخة الحالية تجريبية**: الإعلانات والأسعار وأرقام الملاك بيانات توضيحية، ولوحة الإدارة محلية تعمل داخل متصفح الزائر (الرمز الافتراضي `2530`). راجع «قيود معروفة» في `LAUNCH.md` قبل استخدامها في عمل حقيقي.

## ملاحظة قانونية

جميع العقارات والأسعار وأرقام التواصل في النسخة التجريبية **غير حقيقية**، والصور لأغراض العرض فقط. استبدلها وأكمل بيانات الشركة في `privacy.html` و `terms.html` قبل النشر الفعلي.
